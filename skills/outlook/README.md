# Outlook Skills

Skills for Outlook mail drafting, attachments, sending, scheduling, and verification.

| Skill | Use |
|---|---|
| `outlook-mail-connector-reliability` | Use connector-first Outlook draft, send, and verification workflows. |
| `outlook-connector-draft-attach-send` | Attach local files to connector-created Outlook drafts and send safely. |
| `outlook-scheduled-send-workflow` | Schedule Outlook emails and verify scheduled state. |
