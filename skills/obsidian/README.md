# Obsidian Skills

Skills for maintaining local Obsidian knowledge bases that support BrowserOS long-term memory, job search, outreach, and search feedback loops.

| Skill | Use |
|---|---|
| `obsidian-long-term-memory-workflow` | Save durable BrowserOS memory in a user-approved Obsidian vault instead of chat context or transient run notes. |
| `obsidian-job-search-keyword-intelligence` | Maintain an Obsidian job-search keyword intelligence vault with search logs, keyword maturity, duplicate exclusions, lead notes, and application-path tracking. |
