# LinkedIn People URL Filtering Templates

## Clean People URL

```text
https://www.linkedin.com/search/results/people/?keywords=<encoded_query>
```

## Second-degree + Riyadh URL

```text
https://www.linkedin.com/search/results/people/?keywords=<encoded_query>&network=%5B%22S%22%5D&geoUrn=%5B%22101336206%22%5D
```

## Query templates

- `<role> <city>`
- `<role> <country>`
- `<role> <industry> <city>`
- `<role> <company> <city>`
- `<role variant 1> <role variant 2> <city>`

## Examples

- `project manager riyadh`
- `construction manager saudi arabia`
- `project controls manager riyadh`
- `program manager telecom riyadh`
