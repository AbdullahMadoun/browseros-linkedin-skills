# BrowserOS Core Skills

Core skills that route work, choose connectors before brittle UI, learn unknown sites safely, and handle private approved-answer defaults.

| Skill | Use |
|---|---|
| `browseros-skill-router` | Choose the right BrowserOS skill, connector, built-in skill, local file, or unknown-site learning path. |
| `browseros-new-site-learning-protocol` | Learn unfamiliar websites by mapping controls, state, fields, boundaries, success signals, and recovery paths. |
| `connector-first-action-discovery` | Discover and use connected-app actions before web UI automation. |
| `application-answer-bank-protocol` | Use a private approved-answer bank without putting personal defaults in public skills. |
| `browseros-skill-evolution-loop` | Capture verified live-run insights and promote them into run notes, private memory, existing-skill patches, or new skills. |
