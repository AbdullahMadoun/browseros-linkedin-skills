# Documentation

Use this directory as the public guide layer for the skill repository.

## Start Here

| Document | Purpose |
|---|---|
| `SKILL_CATALOG.md` | Complete grouped catalog of all custom skills. |
| `BROWSEROS_INSTALLATION.md` | BrowserOS provider setup, test step, and Assistant install prompt. |
| `USAGE_IDEAS.md` | Practical chains for search, outreach, applications, Outlook, and skill creation. |
| `REPO_STRUCTURE.md` | Repository layout and organization rules. |
| `SKILL_IMPROVEMENT_WORKFLOW.md` | Exploration-first workflow for creating or improving skills. |
| `PUBLICATION_AUDIT.md` | Checklist before publishing updates. |
| `../CONTRIBUTING.md` | Contribution options, prompt structure, and folder-placement rules. |

## Documentation Rules

- Keep docs public-facing and usage-oriented.
- Do not include old import history, local source paths, private package names, or account-specific notes.
- Keep skill behavior inside each skill's `SKILL.md`; docs should help users find and combine skills.
- Update this index whenever adding or removing public docs.
